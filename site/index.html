WHAT IT DOES 01 — 03

軟體工程開始時，
自動載入交付規則。

當 Agent 開始軟體開發、修 bug、審查程式碼、處理 PR 或部署時，JT Harness 會提供一致的交付規則，協助追蹤工作並確認交付條件。

01 / TRACK

任務有跡可循

先在 Linear 對應 issue；完成後記錄結果、PR、審查、檢查與合併狀態。

02 / ROUTE

工具各司其職

Coolify 資源使用 Coolify Skill；Hetzner Cloud 與 Storage Box 使用 Hetzner Skill。

03 / REVIEW

通過審查門檻

Codex 與 CodeRabbit 各進行一次完整審查；Codex 明確回報使用額度限制時，記錄證據並將其審查條件視為 Pass，不重試。其他 Codex 失敗或沒有結果仍未滿足審查條件。修正問題並驗證後不再要求完整或增量審查。本機全專案 lint 必須通過，main 的既有錯誤也不能跳過；最新提交的必要檢查通過且 GitHub 可合併後，直接合併，不另等人工核准或增加外掛門檻。交付用草稿 PR 先轉為 ready。若 CodeRabbit 的 PR 與 CLI 管道皆受限，則依已滿足的 Codex 審查條件繼續，包含已記錄的額度限制 Pass；GitHub 實際阻擋時記錄原因，不繞過平台限制。僅審查或明確禁止合併的工作不合併。

GET STARTED INSTALL

選擇安裝平台。

從官方儲存庫安裝；新版本會發布在 GitHub Releases。

01 / CODEX Codex

在終端機加入 JurisLM marketplace，並安裝插件：

codex plugin marketplace add https://github.com/jurislm/jt-harness-plugin --ref main
codex plugin add jt-harness-plugin@jurislm-jt-harness

安裝或更新後，開啟新的 Codex session 以載入 Skill。

02 / CURSOR Cursor
  1. 開啟 Customize → Plugins。
  2. 選擇 From GitHub Repository。
  3. 輸入 https://github.com/jurislm/jt-harness-plugin 並安裝 jt-harness-plugin。

更新後重新載入 Cursor，並確認 using-jt-harness Skill 已出現。

SCOPE WHAT IT IS

這是一個 Skill，
不是另一套服務。

JT Harness 的 Skill 會自動觸發並提供交付規則；具體工程作法依工作情境使用對應的 Superpowers Skill。閱讀完整交付規則。

  • ✓ Codex 與 Cursor 的軟體工程交付規則
  • ✓ Linear 追蹤、平台 Skill 路由、審查與合併規則
  • — 不包含 MCP server、slash command、OAuth 或 hosted endpoint
  • — 不發布 npm package；版本透過 GitHub Releases 發布
  • ✓ 授權採用 MIT License
