WHAT IT DOES 01 — 03

Consistent delivery rules,
ready when work begins.

When an agent starts development, fixes a bug, reviews code, works on a pull request, or deploys, JT Harness supplies concise delivery policies for tracking and acceptance.

01 / TRACK

Keep work traceable

Find or create the Linear issue first. Record the outcome, pull request, reviews, checks, and merge status when finished.

02 / ROUTE

Use the right tools

Use the Coolify Skill for Coolify resources, and the Hetzner Skill for Hetzner Cloud and Storage Box.

03 / REVIEW

Clear review gates

Complete one Codex and one CodeRabbit review, resolve findings, and confirm required checks before merging.

GET STARTED INSTALL

Choose your workspace.

Install from the official GitHub repository. Releases are published on GitHub.

01 / CODEX Codex

Add the JurisLM marketplace and install the plugin from your terminal:

codex plugin marketplace add https://github.com/jurislm/jt-harness-plugin --ref main
codex plugin add jt-harness-plugin@jurislm-jt-harness

After installing or updating, start a new Codex session to load the Skill.

02 / CURSOR Cursor
  1. Open Customize → Plugins.
  2. Choose From GitHub Repository.
  3. Enter https://github.com/jurislm/jt-harness-plugin and install jt-harness-plugin.

After updating, reload Cursor and confirm the using-jt-harness Skill appears.

SCOPE WHAT IT IS

A Skill, not
another service.

JT Harness provides automatically loaded delivery rules. The relevant Superpowers Skill handles the engineering method.

  • ✓ Engineering delivery policies for Codex and Cursor
  • ✓ Linear tracking, platform Skill routing, review and merge rules
  • — No MCP server, slash commands, OAuth, or hosted endpoint
  • — No npm package; releases are published on GitHub
