WHAT IT DOES 01 — 03

Consistent delivery rules
for software engineering.

When an agent starts software development, fixes a bug, reviews code, works on a pull request, or deploys, JT Harness provides consistent rules for tracking the work and verifying delivery.

01 / TRACK

Keep work traceable

Find or create the Linear issue first. Record the outcome, pull request, reviews, checks, and merge status when finished.

02 / ROUTE

Use the right tools

Use the Coolify Skill for Coolify resources, and the Hetzner Skill for Hetzner Cloud and Storage Box.

03 / REVIEW

Clear review gates

Use one full review each with Codex and CodeRabbit. If Codex explicitly reports a usage or quota limit, record the evidence and mark its review requirement as Pass without retrying. Other Codex failures or missing results leave the requirement unmet. Resolve findings and verify fixes without further full or incremental reviews. Local full-project lint must pass, including existing main failures. Once current-head required checks pass and GitHub reports the PR mergeable, merge directly without additional human approval or plugin-specific gates. Mark delivery drafts ready first. If both CodeRabbit routes are limited, rely on the satisfied Codex review requirement, including a documented quota-limit Pass. Record actual GitHub blockers without bypassing platform restrictions. Do not merge review-only or explicitly no-merge work.

GET STARTED INSTALL

Choose your platform.

Install from the official repository. New versions are published on GitHub Releases.

01 / CODEX Codex

Add the JurisLM marketplace and install the plugin from your terminal:

codex plugin marketplace add https://github.com/jurislm/jt-harness-plugin --ref main
codex plugin add jt-harness-plugin@jurislm-jt-harness

After installing or updating, start a new Codex session to load the Skill.

02 / CURSOR Cursor
  1. Open Customize → Plugins.
  2. Choose From GitHub Repository.
  3. Enter https://github.com/jurislm/jt-harness-plugin and install jt-harness-plugin.

After updating, reload Cursor and confirm the using-jt-harness Skill appears.
